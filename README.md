# Shakespeare 90s Web Experience 🎭💾

Šis ir **klases darbs**, kas izveidots, lai iztestētu un praktizētu **HTML** un **CSS**.

Projekta galvenais varonis ir pats **William Shakespeare**, tikai šoreiz viņš ir iestrēdzis 90. gadu internetā. 😎

## Projekta mērķis

Šī projekta mērķis ir:

* praktizēt HTML lapas struktūru;
* trenēties darbā ar CSS;
* izmantot `header`, `nav`, `section`, `aside`, `article`, `footer` un citus HTML elementus;
* pievienot attēlus un pogas;
* izveidot responsive dizainu;
* saprast, cik daudz neona krāsu ir par daudz.

Atbilde: **neona krāsu nekad nav par daudz.**

## Par projektu

Mājaslapā ir izmantots fragments no:
